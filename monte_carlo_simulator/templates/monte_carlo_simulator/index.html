Not the same as Historical Backtest. That tool replays the ~96 sequences that actually happened. This one generates thousands of randomly simulated futures — each year's return drawn from a distribution you set — to show the realistic spread of outcomes, not just one number.

Independent of income — only the rate matters (same trick as Savings Rate Explorer).

Each simulation draws a random annual real return for every year of the horizon (independently, from a normal distribution with the mean and volatility you set above), compounds monthly, and checks whether the target was reached. Run enough of these and the spread of outcomes tells you something a single constant-return assumption never can: how much luck/timing genuinely matters. This is a standard, widely-used technique (the same kind of thing tools like FIRECalc's Monte Carlo mode do) — but the output is only as good as the assumed mean/volatility, which are estimates, not guarantees. See Historical Backtest for the same question answered with real historical sequences instead of random draws.
